## E1.2 — Ввод веса

**Критерий приёмки:** замер вводится за 3 секунды, дата по умолчанию — сегодня.

- [x] E1.2.1 Модель `Measurement` с `kind` и `value`
- [x] E1.2.2 Валидация: вес 30–300 кг, один замер веса на дату
- [x] E1.2.3 Компактная форма ввода, числовая клавиатура, шаг 0.1
- [x] E1.2.4 Turbo Stream: после отправки экран не перезагружается

---

## E1.3 — Ввод талии

**Критерий приёмки:** замер талии сохраняется, отображается отдельно от веса.

- [x] E1.3.1 Переиспользовать `Measurement` с `kind: :waist`
- [x] E1.3.2 Валидация: 40–200 см
- [x] E1.3.3 Форма ввода
- [x] E1.3.4 Подсказка: натощак, утром, раз в неделю

## E1.4 — Скользящее среднее

**Критерий приёмки:** среднее считается корректно при пропущенных днях; при менее чем 3 замерах в окне показывается «нужно больше замеров».

- [x] E1.4.1 Сервис расчёта среднего за 7 дней
- [x] E1.4.2 Обработка окна с недостаточным числом замеров
- [x] E1.4.3 Юнит-тесты: полное окно, пропуски, пустое окно, один замер
