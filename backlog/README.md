# Бэклог v1

## Как устроено

Три уровня:

```
Эпик   E3           крупный блок функциональности, один файл
 └ Стори  E3.2      пользовательская ценность, есть критерий приёмки
    └ Таска E3.2.1  единица работы, 0.5–4 часа, критерия приёмки нет
```

Один файл на эпик. Не трогаешь чужой файл — не создаёшь конфликтов, не листаешь простыню.

## Статусы

| Метка | Значение |
|---|---|
| `[ ]` | не начато |
| `[~]` | в работе |
| `[x]` | сделано |
| `[-]` | отменено, причина в скобках |

Стори считается сделанной, когда выполнены все её таски **и** соблюдён критерий приёмки.

## Переезд в настоящую тикетницу

Пока один разработчик — markdown в репозитории оптимален: diff, история, правки в том же PR, что и код.

Когда появится второй человек — GitHub Issues:

- эпик → label `epic:E3` + milestone
- стори → issue
- таска → чекбокс внутри issue
- доска → GitHub Projects, колонки Todo / In progress / Done

Файлы конвертируются скриптом через `gh issue create`. Формат ниже это учитывает: заголовок стори = заголовок issue, критерий приёмки = тело, таски = чеклист.

## Спринты

| # | Содержание | Результат |
|---|---|---|
| 1 | E0, E1 | Приложение стоит на телефоне, вводится вес и талия, виден график |
| 2 | E3 | 3 ротации и 12 рецептов в базе, валидатор зелёный |
| 3 | E2, E4 | Цель поставлена, план недели создан, прогресс виден |
| 4 | E5, E6 | Полный цикл: закупился → приготовил → ешь |
| 5 | E7 + шлифовка | v1 закрыт |

**Спринт 2 — самый недооценённый.** Это ручная работа: написать рецепты, приготовить их лично, замерить время секундомером, съесть на 3-й день хранения. Кодить приятнее, поэтому этот спринт все пропускают и потом получают мёртвый продукт.

**После спринта 5: 4 недели использования без единого коммита.** Раздражения записывать в отдельный файл. Только потом планировать v1.5.

## Вне v1

Осознанно отложено:

- Галочки на приёмах пищи, логирование съеденного — ADR-001
- Выбор и замена отдельных блюд, кастомизация рецептов
- Библиотека рецептов с поиском и фильтрами
- Алгоритмическая генерация меню
- Автоматическая параллелизация шагов готовки
- Мультипользовательский режим, публичная регистрация, онбординг для чужих
- Семейные порции
- Оффлайн-запись с синхронизацией
- Пуш-уведомления
- Интеграции: трекеры, умные весы, HealthKit
- Любой AI-функционал
