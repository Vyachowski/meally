# 04 — Контент: правила рецептов и ротаций

Самый дорогой актив проекта. Код пишется за недели, контент — тоже за недели, но это все недооценивают.

## Объём v1

| Сущность | Количество |
|---|---|
| Ротации | 3 |
| Рецептов на ротацию | 4 (завтрак, обед, перекус, ужин) |
| Уникальных рецептов | **12** |
| Ингредиентов в справочнике | ~50–60 |
| Сессий готовки на ротацию | 2 |

## Жёсткие фильтры рецепта

Рецепт не попадает в ротацию, пока не выполнены **все** пункты:

- [ ] Безглютеновый: все ингредиенты с `gluten_risk != :contains`
- [ ] `cook_method` ∈ `{one_pot, sheet_pan, no_cook, overnight}`
- [ ] `active_minutes <= 20` — замерено секундомером, не на глаз
- [ ] Не более 8 ингредиентов
- [ ] Все ингредиенты есть в обычном супермаркете
- [ ] `storage_days >= 3` для завтрака, обеда и ужина
- [ ] Масштабируется коэффициентом 0.7–1.4 без изменения технологии
- [ ] **Проверено лично на 3-й день хранения** — съедобно, не потекло, не заветрилось

## Правила ротации

Ротация — сбалансированный день, повторённый 7 раз. Значит **день должен быть идеальным**, ошибка умножается на семь.

Требования к сумме четырёх блюд:

| Параметр | Норма |
|---|---|
| Белок | 1.8–2.2 г/кг массы тела |
| Жир | ≥ 0.8 г/кг |
| Клетчатка | ≥ 30 г |
| Овощи | в каждом основном приёме |
| Жидкие калории | 0 |
| Сумма БЖУ vs целевой калораж | ±3 % |

Отклонение — ротация не проходит валидатор и не заливается.

## Вкусовая усталость

Три ротации, смена **раз в 2 недели** по кругу (`order_index`). На фиксированном меню люди обычно выдерживают 2–4 недели.

Обязательно: **кнопка досрочной смены ротации**. Надоело на 5-й день — лучше переключиться, чем бросить. Это не баг дисциплины, это норма.

Ротации должны отличаться **вкусовым профилем**, а не только ингредиентами: например средиземноморский / азиатский / славянский. Смена риса на гречку не считается сменой.

## Скрытый глютен

Не в очевидных местах. Ингредиенты, требующие `gluten_risk: :check_label`:

- соевый соус
- бульонные кубики и концентраты
- готовые соусы, кетчуп, горчица
- овёс — нужен именно сертифицированный GF (перекрёстное загрязнение)
- колбасные изделия, сосиски, фарш промышленный
- смеси специй
- всё, где в составе «крахмал» без уточнения
- разрыхлитель
- плавленый сыр, некоторые йогурты с добавками

В списке покупок такие позиции подсвечиваются меткой «проверь состав».

## Разрешённые источники углеводов

После исключения пшеницы, ржи и ячменя:

рис · картофель · батат · гречка · киноа · кукуруза · пшено · чечевица · фасоль · нут · сертифицированный GF-овёс

Удобное совпадение: всё это дёшево и просто в готовке.

## Формат хранения

Файлы в репозитории, заливаются rake-задачей (ADR-008).

```
content/
├── ingredients.csv
├── recipes/
│   ├── breakfast/*.yml
│   ├── lunch/*.yml
│   ├── snack/*.yml
│   └── dinner/*.yml
└── rotations/*.yml
```

Пример рецепта:

```yaml
name: Запечённая курица с овощами на противне
meal_slot: dinner
cook_method: sheet_pan
active_minutes: 12
passive_minutes: 40
storage_days: 4
freezable: true
servings_per_batch: 5
ingredients:
  - { id: chicken_thigh_skinless, qty: 1000 }
  - { id: potato, qty: 800 }
  - { id: broccoli, qty: 500 }
  - { id: olive_oil, qty: 30 }
  - { id: paprika, qty: 8 }
steps:
  - { text: "Разогреть духовку до 200°C", timer_seconds: 600 }
  - { text: "Нарезать картофель кубиком 2 см, выложить на противень" }
  - { text: "Добавить курицу и брокколи, полить маслом, посыпать паприкой" }
  - { text: "Запекать 40 минут", timer_seconds: 2400 }
  - { text: "Разложить по 5 боксам, остудить перед закрытием крышки" }
```

## Раскладка по боксам

Для каждой сессии готовки прописывается вручную:

- что в холодильник, что в морозилку
- до какой даты годно
- что доготавливается на месте (например, зелень добавляется перед едой)

## Валидатор

Rake-задача `content:validate` проверяет:

1. Все ингредиенты рецептов существуют в справочнике
2. Нет ингредиентов с `gluten_risk: :contains`
3. `active_minutes <= 20`, ингредиентов ≤ 8
4. У каждой ротации ровно 4 блюда, по одному на слот
5. БЖУ ротации попадает в нормы
6. `storage_days` покрывает дни между сессиями готовки

Красный валидатор = контент не заливается.
