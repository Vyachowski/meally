# 06 — UX: четыре вкладки

Нижняя навигация, четыре вкладки. Переключение через Turbo, без перезагрузки.

```
[ Прогресс ]  [ Покупки ]  [ Готовка ]  [ Профиль ]
```

Иконки вкладок несут состояние: галочка на «Покупках», когда всё куплено; галочка на «Готовке», когда все сессии выполнены.

---

## Вкладка 1 — Прогресс

Главный экран, открывается по умолчанию.

**Блок 1: где я.**
- Текущее значение primary-метрики (талия) крупно
- Скользящее среднее веса — вторым числом
- Старт → сейчас → цель, полоса прогресса
- Статус: опережаешь / по плану / отстаёшь (см. `05-formulas.md` §8)
- Прогнозная дата: «примерно к 14 марта»

**Блок 2: неделя.**
Таймлайн текущей недели:

```
● Закупка — суббота          [✓]
● Готовка №1 — воскресенье   [ ]
● Готовка №2 — среда         [ ]
```

Правила:
- Текущий шаг визуально выделен
- Галочки **приглушены**, а не заблокированы, пока не выполнен предыдущий шаг. Жёсткая блокировка ломает реальные сценарии (докупил по дороге)
- После отметки готовки показывается «свежая партия до \<дата\>»

**Блок 3: быстрый ввод веса.**
Поле и кнопка прямо на главной. Ввод занимает 3 секунды, иначе замеров не будет.

**Чего здесь нет:** галочек на приёмах пищи (ADR-001), меню на неделю (оно одинаковое, смотреть нечего).

---

## Вкладка 2 — Покупки

Список на текущую неделю. Открывается в магазине, часто при плохой связи → должен работать из кэша.

- **Группировка по отделам магазина**, не по блюдам. Ходишь по залу, а не по рецептам
- Порядок отделов: овощи → мясо → молочка → бакалея → заморозка → прочее
- Чекбокс на позиции: отмеченное уезжает вниз секции, не исчезает
- Позиции с `gluten_risk: :check_label` — метка «проверь состав», визуально заметная
- Свайп «уже есть дома» — позиция уходит из активного списка
- Внизу: примерная сумма чека
- Когда всё отмечено — галочка на иконке вкладки и на таймлайне прогресса

Количества — уже округлённые до упаковок: «Рис 1 кг», а не «Рис 840 г».

## Вкладка 3 — Готовка

**Экран списка сессий.**
```
Готовка №1 — воскресенье
Курица с овощами + овсянка на 3 дня
25 мин активно · 55 мин всего
[Начать]
```

**Пошаговый режим.**
- Один шаг на экран, крупный шрифт — читается с расстояния метра, руки грязные
- Кнопка «дальше» на всю ширину
- Таймер на пассивных шагах: запуск в один тап, работает в фоне, звук по окончании
- Экран не гаснет во время готовки (Wake Lock API)

**Итоговый экран.**
Раскладка по боксам: что в холодильник, что в морозилку, до какой даты годно. Отметка «готово» закрывает сессию и обновляет таймлайн.

---

## Вкладка 4 — Профиль

- Сводка: старт / сейчас / цель / осталось — по обеим метрикам
- **Стрик недель.** Неделя засчитывается при выполненных закупке, всех готовках и ≥ 2 замерах веса
- График веса: точки замеров + линия скользящего среднего + плановая траектория
- История замеров, удаление ошибочных
- Параметры профиля: рост, возраст, активность. Изменение пересчитывает TDEE
- Текущая ротация + кнопка «сменить ротацию» (ADR-004)
- Экспорт данных в JSON

---

## Общие правила

1. **Ноль модальных окон подтверждения** кроме удаления цели
2. **Ноль пустых состояний без действия** — если нет плана, экран предлагает создать
3. Все действия обратимы: снял галочку — состояние вернулось
4. Никаких поздравительных экранов и анимаций конфетти. Раздражает со второго раза
5. Тёмная тема обязательна: готовка бывает поздно вечером
